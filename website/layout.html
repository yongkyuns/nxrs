NXRS

An experimental Rust-based firmware development environment on top of NuttX.

Embedded projects need hardware access, data processing, communication and recovery. NXRS organizes these into reusable components, with platform profiles describing the hardware configuration.

Applications use ordinary Rust std, threads and event-driven services. NuttX provides the RTOS and board support. This keeps application logic separate from hardware integration and makes components easier to test and reuse.

Read the reasoning behind NXRS →

Implementation and validation

The navigation and camera applications use the component model. Basic validation includes host tests, firmware execution in the NuttX simulator and QEMU, and on-board performance and memory measurements.

Architecture at a glance

NuttX supplies the operating system. Rust std and peripheral wrappers connect that foundation to reusable firmware components; platform profiles describe the product's bindings.

Architecture overview · Engineering reference

Applications

The navigation example connects sensor, fusion and health services, with control commands and explicit shutdown. The camera application combines capture, detection, gateway delivery and client-visible state.

The documentation includes setup instructions, implementation details and test results. More examples and evaluations are added as development continues.
