Firmware development with Rust and NuttX

NXRS

An experimental, general-purpose Rust firmware development environment built on NuttX.

Applications use ordinary Rust standard-library APIs, threads and event-driven components. NuttX supplies the RTOS and board support; NXRS provides the Rust integration, peripheral interfaces, reusable components and platform profiles.

The guide starts with a small application, then covers services, hardware access, configuration, networking, storage and testing. The framework does not require a particular application domain or messaging middleware.

Implementation and validation

Basic validation includes host tests, target integration checks, execution in the NuttX simulator and QEMU, and on-board performance and memory evaluations.

Architecture at a glance

NuttX supplies the operating system. Rust std and peripheral wrappers connect that foundation to reusable firmware components; platform profiles describe the product's bindings.

Architecture overview · Design reasoning

From components to an application

For a connected device, hardware access, command processing, recording and network communication can be separate components. The application decides how they interact; platform configuration supplies the device and resource bindings.

The documentation explains those responsibilities independently of the use case. Optional examples show both small API patterns and larger applications.
