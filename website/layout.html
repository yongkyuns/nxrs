RUST ON NUTTX

Ordinary Rust.
Embedded firmware.

NXRS is an experimental Rust-based firmware development environment on top of NuttX. Build applications from reusable components, with familiar standard-library APIs.

Start with the host demo →Explore the architecture

Independent project. Maintained SDK patches. Qualification varies by target.

app/event-demo/src/main.rs
// Create the components and connect their inputs.
let (fusion, inputs) = FusionService::new();
let imu = ImuService::new(inputs.imu);
let gnss = GnssService::new(inputs.gnss);

// Each active service owns its execution.
let fusion = fusion.start()?;
let imu = imu.start()?;
let gnss = gnss.start()?;

HOW IT FITS TOGETHER

A Rust environment.
A NuttX foundation.

NuttX supplies the RTOS and board support. NXRS connects that foundation to ordinary Rust and a composable firmware stack.
