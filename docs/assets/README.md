# Architecture artwork

The website and engineering references share one set of editable SVG diagrams.
They use the approved overview's rounded containers, muted blue/orange accents,
light and dark palettes, and short labels. Each figure explains one relationship;
its caption states the relevant scope.

## Regenerate or verify

From the repository root, with Node.js installed:

```sh
node docs/assets/render-architecture.mjs
node docs/assets/render-architecture.mjs --check
```

The generator contains the labels, layout and connections. It writes matching
light and `-dark.svg` files beside itself. `--check` compares all generated bytes
without changing files and fails for missing or stale output. Commit the source
and generated SVGs together. Website validation checks reproducibility.

Each SVG has a scalable `viewBox`, a descriptive title, and an accessible text
alternative. Guide figures use an 800-pixel design width; their text remains
editable. Check the generated artwork visually when changing labels or routing,
including both themes and the website's narrower reading width. An SVG that
parses correctly can still contain overlapping text or ambiguous connections.
